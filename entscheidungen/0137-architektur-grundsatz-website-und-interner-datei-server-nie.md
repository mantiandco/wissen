# Architektur-Grundsatz: Website und interner Datei-Server nie auf derselben Maschine

## Kontext

Im Absatz „Taibs Gewichtung (2. September)“ zur Hoster-Auswahl; der Datei-/Backup-Server bleibt eine eigene, spätere Entscheidung.

## Entscheidung

**Architektur-Grundsatz, entschieden: öffentliche Website und interner Datei-Server gehören nie auf dieselbe Maschine**; der Server für zentrale Dateien und Backups ist eine eigene, spätere Entscheidung und wählt nicht den Website-Hoster.
