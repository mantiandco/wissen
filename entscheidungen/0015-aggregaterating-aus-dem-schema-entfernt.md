# aggregateRating aus dem Schema entfernt

## Kontext

Wiederaufnahme ist an eine Bedingung geknüpft: echte Einzelbewertungen sichtbar auf der Seite.

## Entscheidung

**`aggregateRating` ist aus dem Schema entfernt.**

## Begründung

Das JSON-LD gab 5,0 aus 57 Bewertungen aus. Google verlangt, dass ausgezeichnete Bewertungen auf derselben Seite sichtbar sind und nicht die eigene Organisation selbst bewerten. **Eine selbstbezügliche Bewertungsauszeichnung kann eine manuelle Maßnahme auslösen — dann verschwinden alle Rich Results der Domain, nicht nur die Sterne.** Die sichtbare Proof-Zeile bleibt: Sie ist Werbung, keine Auszeichnung. Wieder aufnehmen erst, wenn echte Einzelbewertungen auf der Seite stehen.
