# Sprachvollständigkeit ist eine Gatterfrage

## Kontext

Ausführung des Gatters in 10.1b.

## Entscheidung

**Sprachvollständigkeit ist eine Gatterfrage, keine Absprache — Taibs Auflage vom 25. August.** Jede neue oder geänderte Seite muss **alle aktiven Sprachen** mitführen. Eine deutsche Seite ohne englisches Gegenstück darf nicht bestehen können.

## Begründung

**Begründung in unserer eigenen Sprache:** Das Vergessen einer Übersetzung ist derselbe Fehler wie eine Prüfung, die besteht, weil sie nichts angefasst hat — ein Mangel, der schweigt. **Er wird deshalb nicht ermahnt, sondern gemessen.** Ausführung in 10.1b.
