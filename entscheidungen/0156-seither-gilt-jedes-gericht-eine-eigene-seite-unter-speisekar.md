# Seither gilt: Jedes Gericht eine eigene Seite unter `/speisekarte/<slug>`, Schranke: Seite

## Kontext

Nachfolger der aufgehobenen Entscheidung „D3 — nur acht Gerichtseiten“ — aus dem Abschnitt gezogen, der sagt, was seither gilt.

## Entscheidung

**Aufgehoben.** Jedes Gericht bekommt eine eigene Seite unter `/speisekarte/<slug>`. An die Stelle der festen Zahl tritt eine Schranke: **Die Seite entsteht, sobald `intro` gefüllt ist.** Eine leere Seite ist schlechter als keine.
